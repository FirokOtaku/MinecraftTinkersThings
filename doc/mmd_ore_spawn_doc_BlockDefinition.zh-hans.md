# 方块定义方式

您可以通过调整方块定义, 在一个生成器内定义生成多种方块/使用矿物辞典/指定方块数据.

一份基础 (但不完整) 的例子如下:

```json
{ "name": "minecraft:wool", "metaData": 0, "chance": 100 }
{ "name": "chisel:limestone2", "state": "variant=7", "chance": 100 }
{ "name": "ore:silver_ore", "chance": 100 }
```

上面的 3 个例子分别代表:

1. Minecraft 原版的白色羊毛;
2. 来自模组"凿子"的石灰石方块变种之一;
3. 使用矿物辞典指定的银矿石.

此外, 您可以为每一条方块定义指定一个生成几率.

"metaData"字段支持 Minecraft 1.12 及更低版本,  
但 metadata 系统已经在 Minecraft 1.13 中完全移除.

> **译注**
> 实际上, 方块定义中唯一必须存在的部分是`name` (方块注册名),  
> 但为每条定义附上一个`chance` (原始概率) 是个好习惯: 它决定了方块列表中的每一个方块被选中的几率  
> `state`字段用于指定方块状态, 在 Minecraft 1.13 及更高版本中用来替代`metaData`  
> 上面的例子中三个对象写在了同一个代码块里, 只是为了并列展示写法;  
> 在实际配置文件中, 它们应当是`blocks`数组内的三个元素, 彼此之间用逗号分隔
